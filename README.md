## 🎯 What I Build

I work at the intersection of **technology, automation, and visual storytelling**. My strongest work turns scattered ideas into usable systems: web platforms, creator tools, internal workflows, portfolio experiences, and production-ready digital interfaces.

- **Digital Products**: React, Next.js, TypeScript, Tailwind CSS, API-driven interfaces, and responsive user experiences.
- **Automation Systems**: GitHub Actions, AiSensy, Google Sheets API, email workflows, WhatsApp reminders, and lightweight CRM logic.
- **Creative Technology**: media-heavy websites, cinematic portfolio systems, motion-led interfaces, and tools for creators.
- **Camera Practice**: cinematography, direction, artist interviews, live music coverage, BTS documentation, and DaVinci Resolve workflows.

## 🚀 Featured Projects

### **[The Shakti Collective Academy](https://theshakticollective.in)**
A music-education and culture platform combining cinematic web presentation with operational automation.
- **Stack**: Next.js, TypeScript, Tailwind CSS, Framer Motion.
- **Automation**: Built WhatsApp reminder workflows using **AiSensy** and scheduled background processing with **GitHub Actions**.
- **Operations**: Connected **Google Sheets API** as a lightweight CRM with India Standard Time calibration for distributed students.

### **[BluePolaroid / Cinematic Canvas](https://bluepolaroid.com)**
My dual-discipline portfolio for cinematography, photography, creative technology, and developer work.
- **Stack**: React, TypeScript, Vite, Tailwind CSS, Framer Motion.
- **System**: Structured data powers 50+ camera projects, category filters, YouTube/Instagram embeds, and a separate dev route.
- **Focus**: A portfolio that behaves like a product, not a static gallery.

### **[Auto Mailer](https://github.com/RaghavSobti37/Auto-Mailer)**
An automation project for structured outreach, repeated follow-ups, and email-process efficiency.
- **Focus**: Reduce repetitive manual communication work.
- **Use case**: Faster follow-ups, reusable outreach flows, and practical operations automation.

### **[Resume Generator](https://github.com/RaghavSobti37/Resume-Generator)**
A resume-building tool that connects GitHub projects with AI-assisted project descriptions and clean developer-ready output.
- **Focus**: GitHub project ingestion, AI-supported writing, and structured resume generation.
- **Live**: [resume-generator-sandy.vercel.app](https://resume-generator-sandy.vercel.app)

### **[Photo Cleaner App](https://github.com/RaghavSobti37/photo-cleaner-app)**
A Streamlit-based photo utility for organizing image collections and experimenting with practical media workflows.
- **Stack**: Python, Streamlit.
- **Focus**: Media-library cleanup and lightweight image workflow tooling.

### **[CoreKnot](https://github.com/RaghavSobti37/CoreKnot)**
A product and workflow systems project for connecting business information, user actions, and operational tasks into a cleaner digital experience.
- **Focus**: Operations UX, workflow management, and connected internal-tool foundations.
